# Day 9, Assignment 2 — write your own assembly

A blank RISC-V assembly test you can edit freely.

## Do
1. Write your instructions in `assign2.S` (in the marked area).
2. Set the expected value for the self-check.
3. `./run.sh` — assembles it, runs on Spike, and writes `work/assign2.disass`
   and `work/assign2.dump`. **PASS = exit 0.**

Uses the same bare-metal environment as the other tasks (`../riscv_test.h`, `../link.ld`).
